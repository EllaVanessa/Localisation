# Localisation App

Application Android de géolocalisation utilisant GPS, PHP, MySQL et Google Maps.

##  Fonctionnalités

- récupération de la position GPS
- envoi des coordonnées avec Volley
- stockage dans MySQL
- affichage Google Maps

## Technologies

- Android Studio (Java)
- PHP
- MySQL
- XAMPP
- Volley
- Google Maps SDK

##  Base de données

Base :
`localisation`

Table :
`position`

##  Exécution

1. lancer Apache et MySQL avec XAMPP
2. créer la base `localisation`
3. lancer l’application Android
4. envoyer une position GPS
